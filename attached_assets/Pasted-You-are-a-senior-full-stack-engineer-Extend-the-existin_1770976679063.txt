=====================================================
A) GODOWN PICKUP APPROVAL (DELIVERY MAN → GATEKEEPER)
=====================================================
FLOW (MUST):
1) Delivery Man logs in → “Godown Pickup” module.
2) He selects:
   - Vehicle (vehicle number / type)
   - Vehicle Owner Name (required field; can be tied to Vehicle record)
   - Cylinder categories/products (dynamic from DB)
   - Quantity per product
3) He clicks “Send Request”.
4) Gatekeeper receives request in Gatekeeper Inbox.
5) Gatekeeper physically checks vehicle loading/capacity and verifies actual loaded count.
6) Gatekeeper Approves/Rejects with remarks.
7) On Approve:
   - Approved quantities become official “Issued to Trip”
   - StockMovement recorded (ISSUE)
   - Trip Draft auto-created
8) Delivery Man sees “Approved → Start Trip” interface.

IMPORTANT:
- Delivery man cannot start trip without gatekeeper approval.
- Gatekeeper approval screen must include “Qty Approved” for each item.

=====================================================
B) DELIVERY TRIP + GODOWN RETURN (END-OF-TRIP RETURN)
=====================================================
Trip lifecycle:
- DRAFT (approved pickup, not started)
- ACTIVE (started)
- COMPLETED (ended + return submitted)
- CLOSED (gatekeeper verified return)

NEW REQUIREMENT: RETURN TO GODOWN (MUST)
When delivery man finishes deliveries and ends trip, he must also submit “Return to Godown” details:
- Remaining full cylinders returned to godown (by product qty)
- Empty cylinders returned to godown (by product qty)
- Optional: damaged/leak/other exception counts
- Notes + optional photo proof

FLOW:
1) Delivery man taps “End Trip”
   - System generates trip summary popup (sales + money + delivered/empties)
2) Then system shows “Return to Godown” screen:
   - Pre-filled remaining stock based on issued - delivered
   - Delivery man confirms and submits return quantities
3) Gatekeeper receives “Return Verification” request:
   - Gatekeeper checks returned stock physically
   - Gatekeeper confirms/adjusts return quantities
   - On confirmation: StockMovement recorded (RETURN) and Trip becomes CLOSED

NOTE:
- Admin must be able to configure whether “Return Verification” is mandatory.
- Default: mandatory (trip not finalized until gatekeeper verifies return).
