Build a production-ready “Bachan Gas” cylinder booking website on Replit with:

========================
ROLE / PERMISSION SYSTEM
========================
Implement a flexible RBAC system (NOT hardcoded). Admin must be able to:
1) Create NEW roles anytime (e.g., Delivery Man, Gate Keeper, Accountant, Manager, Support, Warehouse, etc.)
2) Rename roles, disable roles, delete roles (with safety checks)
3) Assign permissions to each role using checkboxes (module-based permissions)
4) Create users directly inside a role tab (like “Delivery Man” tab) by filling details
5) Promote/demote users between roles
6) Remove users (soft delete / deactivate)
7) Allow certain roles (e.g., Delivery Man) to create more users of the SAME role if permitted

Default roles:
- SUPER_ADMIN (full access)
- ADMIN (full access except managing SUPER_ADMIN)
- DELIVERY_MAN
- GATE_KEEPER
- ACCOUNTANT

ADMIN must be able to add MORE roles later without code changes.

========================
ADMIN USER CREATION FLOW
========================
In Admin Panel:
- A “Staff & Roles” section exists with tabs for each role (Delivery Man / Gate Keeper / Accountant / etc.)
- Inside each role tab, admin can click “Add [Role]” and fill:
  - Full Name
  - Mobile Number
  - Email (optional for roles that use OTP login) OR required (choose email+password for all to keep simple)
  - Password (auto-generate option + copy button)
  - Address (optional)
  - ID Proof fields (optional: Aadhar last 4 digits, PAN last 4, etc.)
  - Joining Date
  - Notes
  - Status: Active/Inactive
- On save:
  - The user is created in DB and immediately can login as that role
  - They appear in the role list/table
- Admin can:
  - Edit details
  - Reset password
  - Deactivate/activate
  - Remove (soft delete)
  - Reassign role

Also implement: “Role can manage same role”
- If enabled by permission, a Delivery Man (or Gate Keeper) who has “STAFF_CREATE_SAME_ROLE” permission can add/remove delivery men (only their role), but cannot touch other roles.

========================
ROLE-SPECIFIC SCREENS
========================
A) Delivery Man Dashboard (/delivery/dashboard)
- Can see ONLY orders assigned to them (unless permission DELIVERY_VIEW_ALL)
- Each order card:
  - customer name, phone, address, product, qty, payment method
  - buttons to update status:
    - Picked Up / Out For Delivery / Delivered / Failed
  - “Delivered” requires OTP from customer OR optional photo proof (configurable)
- Delivery man cannot edit products/categories unless granted permissions.

B) Gate Keeper Dashboard (/gatekeeper/dashboard)
- Can see “Today’s outgoing/return cylinders” list
- Can mark: “Cylinder Issued” / “Cylinder Returned” (simple stock movement log)
- View only what gatekeeper is allowed.

C) Accountant Dashboard (/accountant/dashboard)
- Can see payments, order amounts, COD pending, paid orders
- Can export simple report CSV
- Can mark “COD Received” for delivered COD orders (if permission granted)

D) Admin Dashboard (/admin)
- Full access to everything based on permissions.
